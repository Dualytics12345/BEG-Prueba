Módulo 1

Fundamentos de Accesibilidad y Diseño Incluyente

Clase en Video: Principios de Maquetación Universal

Duración: 05:20 min — Haz clic para reproducir la demostración

Puntos Clave de la Lección

La accesibilidad web no es una característica opcional, sino una responsabilidad ética y técnica. Diseñar páginas web incluyentes garantiza que personas con diversas capacidades (visuales, auditivas, motoras o cognitivas) naveguen de forma autónoma.

Contraste Visual

Asegura una relación de contraste mínima de 4.5:1 entre el texto y el fondo.

Navegación por Teclado

Todos los elementos interactivos deben ser accesibles mediante la tecla TAB.

Estándares WCAG y Semántica HTML5

El uso correcto de etiquetas semánticas (`<header>`, `<main>`, `<nav>`, `<article>`, `<button>`) ayuda a los lectores de pantalla a estructurar la información para usuarios con discapacidad visual.
